MedicarePlus: smart medical diagnostic system

  • FastAPI
  • React.js
  • PyTorch
  • Keras
  • HL7 FHIR R4
  • Docker
  • Grad-CAM

7 pathologies 93.38% average accuracy <100 ms inference

  • Multi-pathology diagnostic pipeline. A clinical screening platform covering pneumonia, malaria, diabetes, CKD, liver disease, cardiac disease and breast cancer.
  • Explainable AI. An interpretability engine that uses Grad-CAM gradients to overlay JET colormap heatmaps on chest X-rays, alongside feature contribution percentages from tree models on tabular data.
  • Healthcare interoperability. A two-way conversion layer that turns multimodal patient observations and findings into standard HL7 FHIR R4 JSON bundles, mapped to LOINC and SNOMED-CT.
  • Cloud-native full stack. Asynchronous REST APIs built with FastAPI, Uvicorn and Pydantic, paired with a responsive React.js interface. Frontend and backend run as microservices with Docker and Docker Compose.

Big data e-commerce analytics platform: heavy user intelligence system

  • Python
  • Flask
  • Pandas
  • Scikit-learn
  • NumPy
  • Chart.js
  • Bootstrap 5
  • REST API
  • Docker

10,000 transactions 1,000 users 5 categories

  • Behavioral analytics pipeline. An end-to-end platform that processes all of this data and generates insights in under a second.
  • Heavy user segmentation. A 90th-percentile engine that sorts users into Basic, Prime and VIP tiers and extracts spend, order value and peak-hour KPIs with Pandas.
  • Recommendation engine. Collaborative filtering with Scikit-learn cosine similarity on a user-item matrix, returning each user's top 5 products. New users fall back to popularity ranking.
  • Traffic and load balancing simulation. A 4-server load balancer with auto-scaling at 90% load and load shedding, plus a 24-hour simulation with 3x peak-sale spikes.
  • Interactive dashboard. Flask REST APIs feed a Bootstrap 5 and Chart.js front end that charts live traffic, sales and server load from JSON fetches.
